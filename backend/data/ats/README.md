ATS company directories
=======================

Slug lists copied from [job-board-aggregator](https://github.com/Feashliaa/job-board-aggregator)
(`data/greenhouse_companies.json`, `lever_companies.json`, `ashby_companies.json`).

Those datasets are licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).
Non-commercial use only.

The sweep uses these lists with our existing HTTPS JSON providers. It does not
vendor the aggregator's scraper, HTML extractors, or Workday/BambooHR/iCIMS/Paylocity lists.
